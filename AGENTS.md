# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

This project is temporarily pinned to Expo SDK 56 (rather than the latest 57) because the
SDK 57 update to the Expo Go app was still pending Apple's App Store review. Once that's
approved (or you're using a development build / EAS build instead of Expo Go), it's fine to
upgrade back to the latest SDK — see [README.md](README.md) for the upgrade command.
