# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project is pinned to Expo SDK 54 (`expo@54.0.x` in package.json), rather than the latest
SDK. It was held back while the newer SDK's update to the Expo Go app was still pending
Apple's App Store review. Once that's
approved (or you're using a development build / EAS build instead of Expo Go), it's fine to
upgrade back to the latest SDK — see [README.md](README.md) for the upgrade command.
